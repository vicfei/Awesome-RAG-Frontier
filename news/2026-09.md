## 2026-09 — PixelRAG keeps climbing

[arXiv:2606.28344](https://arxiv.org/abs/2606.28344) — retrieval over rendered pixels instead of parsed text; the repo crossed 10k stars. The "end of web parsing" pitch is overstated, but the direction — parsing-optional RAG — is real. Listed under *Document parsing & multimodal ingestion*.

## 2026-09 — The "RAG as Agent Skill" wave keeps spreading

Since [ConardLi/rag-skill](https://github.com/ConardLi/rag-skill) (Feb 2026, 713★, now archived in favor of garden-skills) showed that hierarchical index files + grep + progressive disclosure can replace a vector pipeline for small local corpora, a follow-up cluster has formed — all tracked on the [Radar](../README.md#-radar--pre-threshold-watchlist): [Skill-First-Hybrid-RAG](https://github.com/lyxhnu/Skill-First-Hybrid-RAG) (skill-first with vector + BM25 fallback), [rag-to-skill](https://github.com/Jia-Hong-Peng/rag-to-skill) (JSONL corpora → verifiable Claude Code skills), [RAG-Data-Curator-Agent-Skill](https://github.com/leichu0612-byte/RAG-Data-Curator-Agent-Skill) (structure-aware chunking as a skill), [enowx-rag](https://github.com/enowdev/enowx-rag) (per-project RAG memory over MCP). None clears the 300★ bar yet. The thesis — the *agent* decides the retrieval strategy instead of a fixed pipeline — is the agentic-RAG direction taking a concrete, filesystem-native shape; semantic recall at corpus scale remains unproven.
